# Series of Calls illustration pack

Six new illustrations were generated with the built-in image-generation tool for this adaptation. The manifest records original files, derived exports and their hashes; these are not recovered upstream binaries. The tool did not report its model identifier.

## Art direction

Witty illustrated operations: crisp editorial forms, restrained texture, dark teal `#102e36`, mint `#bde5ce`, cream, amber and muted violet. Friendly adult technical staff; humour about configuration complexity and misplaced confidence. No real vendor logos, real tenant details, flags, legal certification claims or readable interface text. These scene descriptions summarise the full generation prompts retained in the authoring session.

- **Launch:** communications operations studio linking phones, messages, a meeting room and servers; one cable takes an absurdly circuitous route. Quiet space supports a separately rendered heading.
- **SMB:** small repair shop handling calls, appointments and customer requests; a cable loops around a potted plant. A small team rather than an enterprise call centre.
- **Enterprise:** mixed phone systems, video rooms and staged migration; a trolley of retired phones and a surplus cable collection provide the joke.
- **Government:** accessible civic service, controlled processing and archives, human handoff; a very organised pile of paperwork. No implied procurement approval.
- **Defence:** civilian administrative/training continuity in a remote office; local phones, records, time and backup power while outside connectivity is disconnected. No combat or tactical content.
- **SP:** physical network planning; two apparent alternate paths share the same bridge failure domain. No claim that physical bandwidth creates staffed agent capacity.

## Integration and export

The original PNG outputs are retained under `generated/`. Project WebP exports have 640- and 1280-pixel widths; the social preview is 1200×630. Raster install icons and ICO variants derive from the existing project SVG, with the maskable mark occupying a central safe region. Sharp was used as a local export tool from the available workspace installation, not added as a runtime or build dependency. Rendering uses responsive sources and translated alternative text; the six artwork families are included in the application service worker cache.

The visible source-linked text humour remains in its separate narrative register. The new illustrative jokes do not claim to be verbatim upstream comparisons. Review images visually with the actual desktop/mobile UI before release; DOM and byte/hash checks do not constitute that browser review.
