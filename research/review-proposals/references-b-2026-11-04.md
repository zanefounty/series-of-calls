## Scope and limitations

The source claims were first recorded as historical research assertions; current vendor pages were used only to check the narrow present-day feature examples. A current product overview does not validate historical deployments, customer outcomes, certifications, legal compliance, or plan-specific entitlements. Recommendations are deliberately scoped to what each checked page supports.

One checked source was inaccessible in part: Microsoft's page content was readable but carried an approval/access notice and documented a gated offer. Earlier web retrieval of the pinned GitHub source failed; the connected GitHub tool subsequently returned the exact architecture file. The tree page remains unavailable, and the recommendation is now to revise the broad claim to the file's demonstrated scope. Pricing, portfolio catalogs and product availability are volatile and need dated rechecks before operational or procurement use.
