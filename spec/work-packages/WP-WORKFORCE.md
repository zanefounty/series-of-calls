# WP-WORKFORCE — staffed capacity and operating responsibility

Sources: `uc-new:domain:workforce`, `journeys`, `pricing`, `commercial-roles`; contact-centre product-family rows. Own `src/game/49-workforce.js`, `tests/workforce-operations.test.js`, optional `src/game/92-workforce-ui.js`, and `spec/work-packages/workforce-handoff.md`. Use `SOC_WORKFORCE`, factory `socWorkforceKernel`, optional `s.workforceOps`, version `soc-workforce-1`.

Expose documented command/advance/validate/inspect/fingerprint/source and a pure effective capacity adapter for a core workforce resource. Parent retains existing aggregate fields for saves without this pack; with it, core queue handling and business aggregate demand must consume the same roster-derived snapshot. Return people/entitlements/skills/languages/concurrency or an allocation result without silently creating skills through unioning incompatible individual agents.

Each person has ID, employer/operator, skills, languages, shift, availability, assigned voice/digital work, entitlement and coaching state. Separate named licences, session admission and human availability. One person cannot satisfy two simultaneous full voice loads or combine one person's language with another person's skill. Wrap-up reserves that same person. Digital concurrency is per-person. Customer-operated rosters cannot be edited by the player; BPO control requires a scoped agreement. Customer staffing is an observed external constraint, never a player-owned shortcut.

Desired roster changes provision on a later minute. Active assignment and wrap-up survive edits; reducing capacity cannot erase ongoing work. Allocation is deterministic, bounded and recorded. Forecasts snapshot historical arrivals, horizon and method; stale forecasts warn but do not alter real demand. Coaching occupies explicit work time and cost/capacity, then modifies a documented skill/quality parameter; a purchased licence alone cannot create a trained person. Repeated reads never accrue cost or advance training.

Acceptance IDs 053–058: skill/language on same available person; voice/digital/wrap separation; operator/delegation restrictions; delayed roster change with active assignment; forecast staleness and coaching cost/time; save/worker equivalence and invalid imports. Explain configuration and allocation hooks precisely. Use fictional workforce flavour (e.g. a licence cannot answer a ringing phone) while keeping operational diagnostics concrete. Do not modify central kernel or commercial ledger directly; provide explicit cost events for parent integration.
