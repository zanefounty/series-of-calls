# Verification receipts

Only the small canonical files consumed by repository checks belong here:

- `acceptance.json`: executed acceptance IDs and input hashes; regenerated by `npm run evidence`.
- `browser.json`: browser release receipt. Its presence does not establish current browser acceptance; the release gate checks its input hashes.
- `verification.json`: a concise dated verification summary retained for the delivery tracker, with scope limits and hashes of externally retained audits.

Screenshots, traces, TAP logs, copied builds, browser sessions, failed-run directories and duplicate reports are generated artifacts. They are ignored and must not be added to source commits. CI already uploads its acceptance and gate outputs as workflow artifacts. Keep implementation PRs focused on code, tests, source mappings and concise results.

On 4 November 2026, the owner requested removal of the accumulated raw evidence. The earlier tracked reports remain available in [the preserved Git history](https://github.com/zanefounty/series-of-calls/tree/11e16893a9598f96f340aa07322497219bf2c019/evidence); historical documentation links pin that revision. Local raw archives were removed. No passing result was fabricated, and no gate, readiness flag, source pack or upstream history was changed by this cleanup.
