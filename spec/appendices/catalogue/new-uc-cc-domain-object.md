# New UC CC domain object

| Mapping ID | Proposed representation | Requirement | Behaviour obligation |
| --- | --- | --- | --- |
| uc-new:domain:commercial-roles | Commercial roles and service agreements / domain:commercial-roles | REQ-2b889aa0d4d73d98 | Model vendor, distributor, reseller, SI, MSP, carrier/SP, CPaaS supplier/builder and BPO roles separately. Agreements specify buyer, seller, permitted resale, support ownership, tenant access, obligations, renewal and exit. |
| uc-new:domain:workforce | Contact-centre workforce and agent capacity / domain:workforce | REQ-ef684c98bb36340a | Track skills, languages, shifts, handling, wrap-up, availability and digital concurrency independently of agent licences, trunks and compute. Staffing is directly controllable only when the player or its contracted operator owns that responsibility. |
| uc-new:domain:journeys | Customer journey case and outcome / domain:journeys | REQ-28812c50374d9ebf | Maintain journey and case identity across voice, messaging, bot and human handling. Record resolution, wait, abandonment, repeat contact, customer effort and required contract outcomes. |
| uc-new:domain:messages | Messaging channels and conversations / domain:messages | REQ-655a9d691e39074f | Create distinct channel accounts, participants, consent/permission, templates, response windows, delivery evidence and paused/resumed conversations. Include WhatsApp-like, Messenger-like, SMS/RCS, web chat and workplace chat profiles where supported. |
| uc-new:domain:cpaas-workflows | CPaaS workflow execution / domain:cpaas-workflows | REQ-9af2d006b2b32f47 | Model API calls, callbacks, webhooks, retries, idempotency, authentication, rate limits, delivery state, downstream context and human escalation. Separate application reliability from channel-supplier availability. |
| uc-new:domain:signalling | Call signalling and admission / domain:signalling | REQ-b758f745b15b45e0 | Resolve identity and number policy, then route signalling through platform and SBC dependencies. Model admission, transfer, forwarding, negotiated capabilities, fallback and release independently of media delivery. |
| uc-new:domain:media | Directional media and interaction quality / domain:media | REQ-96268c1dc55521b5 | Evaluate each media direction, relay placement, NAT/firewall paths, codecs, packet loss, jitter, latency, bandwidth and resource limits. A connected session can have failed audio, video or content sharing. |
| uc-new:domain:directory-dialplan | Directory numbers and dial plans / domain:directory-dialplan | REQ-da0f4df910662210 | Create canonical users, extensions, public numbers, aliases, caller identity and permissions. Keep number formatting, extension ambiguity and routing rules explicit across tenants and sites. |
| uc-new:domain:number-porting | Number inventory and porting / domain:number-porting | REQ-db51ec62714632f6 | Track reservation, allocation, assignment, port orders, supplier lead times, acceptance, cutover, failed ports and recovery. Number portability does not by itself migrate identities, recording or workflows. |
| uc-new:domain:emergency | Emergency location routing and notification / domain:emergency | REQ-511dee99efa070bd | Model site/user/device location, permitted routing, calling restrictions and notifications as jurisdiction-scoped requirements. Use synthetic validation and keep emergency service eligibility distinct from ordinary PSTN reach. |
| uc-new:domain:room-joining | Rooms calendars and meeting interoperability / domain:room-joining | REQ-ab54e717f2267a8e | Connect room accounts, identity, calendars, booking, native platform mode, interop provider, joining path, media and capture. Test the selected feature set instead of treating every join button as equivalent. |
| uc-new:domain:identity | Identity federation and administrative access / domain:identity | REQ-744f6caa39ca6f96 | Model provisioning identities, directory links, guests, federation, authentication, certificates, roles, delegated administration and tenant boundaries. Track calendar/content services as explicit dependencies. |
| uc-new:domain:recording | Recording and capture policy / domain:recording | REQ-5a5e46aedc11c26c | Distinguish user recording from policy-based recording. Model capture permission, stream delivery, recorder availability, storage, retention, review and failure behaviour when recording is contractually required. |
| uc-new:domain:speech-processing | Speech and AI processing stages / domain:speech-processing | REQ-b5db36d8b20c5da6 | Create separate stages for speech recognition, speaker attribution, translation, redaction, summarisation, agent assistance and automated handling. Each stage has language support, capacity, latency, quality, cost and permitted processing locations. |
| uc-new:domain:information-lineage | Information outputs and derived lineage / domain:information-lineage | REQ-5ea0af27c76ef95f | Track each output separately with source interaction, participants, processor, storage/backup, access, retention and export destinations. Preserve parent/derived links so a failed or prohibited processing stage affects only the relevant outputs. |
| uc-new:domain:sovereignty | Sovereignty and operating boundaries / domain:sovereignty | REQ-cf5e95a42f52fb64 | Check media, records, metadata, logs and backups independently; inspect processing, key custody, privileged support, jurisdiction and external dependencies. Local hosting or a vendor label cannot satisfy the complete requirement set automatically. |
| uc-new:domain:eligibility | Workload sensitivity and jurisdiction eligibility / domain:eligibility | REQ-8c0f3e7ca74bbcd7 | Represent customer sector, size, sensitivity, workload and country independently. Evaluate feature, deployment, operating boundary and evidence requirements before ranking eligible designs on price or service quality. |
| uc-new:domain:product-evidence | Products offers integration evidence and lifecycle / domain:product-evidence | REQ-475be0a8471d831d | Separate company, product family, offer and instance. Store directional feature subset, prerequisites, cloud/region, support owner, evidence type/date, previews and independent end-of-sale, renewal and support states. |
| uc-new:domain:discovery | Discovery inventory and canonical service model / domain:discovery | REQ-bbfea1e3e5de14fd | Import synthetic users, numbers, devices, sites, applications and dependencies into a canonical inventory. Track discovery confidence, mismatches, unknowns and customer journeys before migration or provisioning. |
| uc-new:domain:provisioning | Provisioning JML and delegated changes / domain:provisioning | REQ-3ec2c90c193eeca4 | Model joiners, movers, leavers, templates, entitlements, number/device assignment, approval where required, bulk execution, partial failure, retry and evidence. Automation reduces work only for the connectors and actions it supports. |
| uc-new:domain:migration | Migration coexistence cutover and recovery / domain:migration | REQ-65e4df84bdf18392 | Plan cohorts, identity/number mappings, coexistence, retained devices, data migration, cutover and rollback/recovery. Validate calling, rooms, queues, recording and integrations throughout the transition. |
| uc-new:domain:journey-testing | Journey testing and interaction inspector / domain:journey-testing | REQ-85c520bc378fb8b6 | Run deterministic synthetic journeys with signalling, directional media, workflow, workforce and information checks. Show the reason chain, failing dependency, contract consequence, recovery alternatives and cost. |
| uc-new:domain:pricing | Typed communications billing and economic ledger / domain:pricing | REQ-178f5e928012b803 | Track seat, room, named/concurrent agent, session, minute, message, API, processing, storage, project and support units independently. Apply allowances, overage and minimum commitments; eliminate internal transfers when consolidating owned businesses. |
| uc-new:domain:substitution | Channel choice bundles and competitive substitution / domain:substitution | REQ-76a8e1aeaba8a926 | Generate underlying customer needs, select among eligible channels and update adoption from outcomes and switching costs. Include messaging, persistent collaboration, video, embedded APIs, assistants, vendor bundles and direct sales as scoped events. |
| uc-new:domain:continuity | Disconnection recovery and service continuity / domain:continuity | REQ-8dfd64ff521dbc5b | Test the promised local or restricted-connectivity journeys against identity, licensing, DNS, time, certificates, management, updates, storage and media dependencies. Recovery must preserve customer context and required records. |
